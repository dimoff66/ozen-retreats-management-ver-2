# Карты домов

Карта дома содержит фоновое изображение и позиции комнат. Карта может быть
назначена самостоятельному дому или группе домов. Схема и формат координат
описаны в [документации базы данных](./database.md#house_maps).

## Рабочая карта

Рабочая карта используется для просмотра назначения комнат, выбора комнаты и
выбора гостя при обмене.

Комнаты на карте отображаются вертикальными прямоугольниками с цветной заливкой
и рамкой более тёмного оттенка. Вверху жирным показывается номер комнаты (или
полное представление комнаты для карты группы домов), ниже — заполнение,
например `1/2`. Внизу располагается индикатор заполнения: синий, пока комната не
заполнена, и зелёный, когда заполнена. Недоступная комната показывается серой,
без индикатора заполнения.

На десктопе при наведении прямоугольник слегка увеличивается.

Сверху карты находятся вкладки с именами карт. При выборе вкладки показывается
соответствующая карта и комнаты. По умолчанию открывается карта, которую
пользователь открывал последней.

Под картой в режиме выбора доступен список комнат, сгруппированный по домам.
Незаполненные комнаты отмечаются синим кружком перед названием, недоступные
отображаются серым. Эта область показывается только в режиме выбора.
