# Роли и рабочие сценарии

Поддерживаемые роли приложения:

```text
admin
manager
organizer
taxi
```

## Admin

Администратор видит боковое меню `Retreats` и `Admin`. В рабочей области ему
доступны вкладки Guests, Rooms, Taxis, Map и History.

В рабочей области ретрита можно работать с гостями и историей, настраивать
доступность комнат и просматривать карту. Admin может создавать и редактировать
поездки такси и управлять их пассажирами. Доступность остальных операций над
гостями определяется текущим интерфейсом.

По умолчанию открывается рабочая область Retreats. Сначала выбирается самый
ранний активный ретрит. В разделе Admin доступны справочники Houses, Rooms,
Retreats и Users с действиями, предусмотренными соответствующими списками.

## Manager

Менеджер не имеет доступа к административной части и сразу открывает рабочую
область. Для выбора доступны активные ретриты.

В рабочей области доступны Guests, Map, Meeting и Check in. Guests показывает
общий список гостей, Map — карту размещения. На Meeting отображаются поездки
такси в виде карточек с флажками выбора, а ниже — гости выбранных поездок,
отсортированные по дому назначенной комнаты. В карточке гостя показываются имя и
отображаемое название комнаты. Для гостя со статусом `booked` доступно действие
Arrived.

На Check in отображаются прибывшие гости и доступно действие заселения. Панель
создания, редактирования и удаления гостей недоступна; остальные действия над
гостем зависят от его текущего статуса.

## Organizer

Организатор привязан к одному ретриту через `users.retreat_id` и не может видеть
другие ретриты. Рабочая область содержит вкладки Guests, View, Taxis и History.
Организатор может создавать гостей, назначать комнаты и просматривать поездки
такси.

Рабочая область открывается сразу. Доступные действия над гостями определяются
ролью пользователя и текущим статусом.

## Taxi

Роль `taxi` используется для работы с поездками для ретрита. Пользователь taxi
может выбирать активный ретрит; рабочая область показывает вкладку Taxis.

## Поездки и пассажиры

Поездки сортируются по `arrival_datetime` по возрастанию. Порядковый номер
карточки вычисляется после сортировки и не хранится в базе. Карточка показывает
номер, время прибытия, имя водителя, количество пассажиров и уникальные названия
домов, в комнаты которых назначены пассажиры.

Создание и редактирование поездки выполняется в отдельной модальной форме.
Выбранная поездка определяет список пассажиров ниже карточек: сначала
показываются уже назначенные поездке пассажиры, затем подходящие под поисковый
запрос гости.

Если гость уже назначен другой поездке, рядом с его именем указывается номер
карточки той поездки. При выборе такого гостя требуется подтверждение смены
поездки; после подтверждения гость переносится в выбранную поездку.

Незарегистрированного дополнительного пассажира можно добавить к выбранной
поездке отдельно от поиска гостей. Admin и taxi могут создавать и редактировать
поездки и управлять пассажирами. Остальные роли могут только просматривать
поездки и пассажиров.
