# Интерфейс и адаптивный дизайн

## Общая компоновка

На широком desktop рабочая область центрируется между симметричными боковыми
зонами. У admin левая зона занята навигацией, у остальных ролей она сохраняется
пустой; справа резервируется зона той же ширины. На небольших экранах боковые
зоны схлопываются.

Название и даты текущего ретрита находятся в самой верхней панели. Сразу справа
от названия расположена кнопка `...` для выбора другого ретрита. Пользователь
выравнивается в правой части topbar.

На mobile у admin сохраняется узкая вертикальная навигация только с двумя
иконками: Retreats и Admin.

## Заголовки вкладок

Компоненты рабочих вкладок поддерживают параметр `showTitle`. Внутри
`RetreatWorkspace` он передаётся как `false`, чтобы заголовок компонента не
дублировал название активной вкладки.

## Размер текста

Для обычного и мелкого UI-текста доступны семь уровней: исходный и шесть
увеличений по 1 px. На desktop используются hotkeys:

```text
Alt +   увеличить
Alt -   уменьшить
```

Ниже исходного размера уменьшение невозможно. Выбранный уровень сохраняется в
`localStorage`. Крупные заголовки не масштабируются вместе с мелким UI-текстом.

## Guests

Таблица гостей должна помещаться в ширину мобильного экрана без выхода за его
границы. Поиск учитывает имя, дату, статус и отображаемое название комнаты.

В карточках гостей имя и status badge располагаются в первой строке. Room/taxi
и action-кнопка располагаются ниже; action остаётся визуально по центру по
вертикали и не должна сжимать имя. Meeting и Check in используют один компонент
карточки и оба показывают status badge.

В форме Add/Edit guest комната выбирается через `HouseMapView`, а не через
выпадающий список. Выбор на карте только меняет `room_id` в состоянии формы;
создание или обновление гостя по-прежнему выполняется только после `Save`. Для
редактируемого гостя проверка вместимости исключает самого этого гостя из
текущей occupancy. В этом режиме нижний список комнат карты скрыт: выбор
выполняется непосредственно по room markers на карте.

## Retreat Rooms

На мобильном экране карточки комнат располагаются по две в строке. Занятая
комната не может быть отключена для ретрита, включая массовое отключение дома.

## Taxi

Карточки поездок узкие, вертикальные и визуально центрированные. На desktop
используется до семи карточек в строке; Meeting использует такой же компактный
формат. Последняя карточка — `Add ride` с круглым `+`. Информация о домах для
выбранной поездки находится под рядом карточек, а не внутри каждой карточки.
